# About

This repository explores 100+ years of NOAA land/sea temperature anomaly data (NOAA NCEI)
 with Climate tipping points

## Data: lsavg.csv | NOAA NCEI
NOAA calculated these global temperature departures using a 5°x5° grid, based on the 1991-2020 average. Global precipitation values use a 2.5°x2.5° grid and departures are relative to the 1991-2020 average. Please note, global precipitation data are processed on a different schedule and released separately from global temperature data.
